# Chapter 8: How to Ask for Help

*Estimated study time: ~1-2 hours*

A short but genuinely useful chapter on debugging in practice and getting help efficiently:

- Read the **full traceback** before searching — the actual error is usually the last line, not the first.
- Reproduce the bug in the **smallest possible script** before posting it anywhere.
- Use the Hugging Face **forums** for usage questions; open a **GitHub issue** only for confirmed library bugs, with a minimal reproducible example, versions of `transformers`/`torch`/`python`, and the full stack trace.
